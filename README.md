**CivicPulse AI** is a premier Digital Public Good (DPG) platform designed to aggregate multilingual citizen infrastructure demand via voice, text, IVR, and messaging channels. By fusing ground-level citizen distress signals with spatial demographic indices and regional public capital expenditure (Capex) data, CivicPulse AI dynamically identifies infrastructure demand hotspots and automatically formulates bankable, governance-ready **Detailed Project Reports (DPRs)** for public investment boards and policymakers worldwide.

---

## 📸 Platform Highlights

- **Grassroots Ingestion**: Multilingual speech recognition and intent extraction supporting 22+ languages and regional dialects.
- **GIS Demand Hotspots**: Spatial clustering engine overlaying citizen grievances onto Aspirational and Tribal district maps.
- **Demographic Disparity Matrix**: Real-time audit of infrastructure deficits vs. historical public budget allocations.
- **Bankable DPR Generator**: Instant EFC/PIB-compliant project reports featuring technical solutions, engineering cost breakdowns, multi-phase timelines, and Socio-Economic ROI (S-ROI).
- **AI Policy Copilot**: Conversational strategic advisor built for Cabinet Secretaries, District Magistrates, and NITI Aayog Fellows.

## 🎯 The Core Problem & Innovation

### The Governance Gap
1. **Linguistic & Technological Barriers**: Millions of rural and non-English-speaking citizens are excluded from traditional public grievance portals due to literacy or language friction.
2. **Reactive & Uncoordinated Planning**: Infrastructure funds are frequently allocated through ad-hoc requests or historic inertia rather than empirical, real-time spatial demand data.
3. **DPR Bottlenecks**: Creating technical, bankable Detailed Project Reports for rural roads, drinking water, healthcare, and power grids manually takes **months to years**, stalling public works.

### The CivicPulse AI Solution
CivicPulse AI closes the feedback loop between citizens and public capital allocation:

## 🚀 Key Modules & System Features

### 🎤 1. Multilingual Multimodal Ingestion Hub
- **Voice & Speech-to-Intent Processing**: Converts raw audio recordings (from phone calls, WhatsApp voice notes, and IVR systems) directly into structured data.
- **Verbatim Vernacular Extraction**: Supports 22+ languages including Hindi, Tamil, Telugu, Bengali, Marathi, Gujarati, Kannada, Odia, Punjabi, Malayalam, Assamese, Urdu, English, and regional dialects.
- **Automated Metadata Tagging**: Extracts sector classification (Water, Roads, Primary Health, Power, Education, Irrigation, Digital), location hierarchy (State, District, Block, Gram Panchayat, Geolocation), Urgency Score (1–100), and Affected Beneficiary Count.
- **Native-Language Citizen Feedback**: Generates real-time vernacular acknowledgement messages back to citizens in their native script to ensure transparency.

### 🗺️ 2. Spatial Geo-Hotspot GIS Map
- **Interactive Spatial Heatmaps**: Visualizes aggregated citizen demand overlaying real-time geo-located clusters, district boundaries, and high-deficit zones.
- **Aspirational & Tribal District Focus**: Built-in prioritization filters for designated vulnerable regions (e.g., Aspirational Districts, Tribal/Forest belts).
- **Cluster Aggregation**: Groups individual citizen requests into macro-level infrastructure projects (e.g., arsenic-free drinking water plants, bridge rebuilds, PHC upgrades).

### 📊 3. Demographic Equity & Disparity Matrix
- **Composite Disparity Gap Index (DGI)**: Quantifies structural inequities by comparing grievance density against past public budget distributions.
- **Infrastructure Desert Identifier**: Automatically flags regions suffering from acute distress combined with historical capital under-investment.
- **Interactive Analytics**: Features radar charts, distribution heatmaps, and ranking leaderboards for public auditors and finance ministries.

### 📄 4. Bankable DPR & Policy Workbench
- **Instant EFC/PIB-Compliant DPR Formulation**: Automatically synthesizes bankable Detailed Project Reports aligned with PM Gati Shakti guidelines and Government of India project formulation standards.
- **Comprehensive Technical Breakdown**:
  - Formal Project Title & Implementing Nodal Ministry
  - Executive Summary & Aggregated Ground Evidence Quotes
  - Engineering & Technical Specifications
  - Capex Financial Plan (Itemized civil works, smart monitoring, O&M)
  - Multi-Phase Execution Timelines (Gantt-compatible deliverables)
  - Socio-Economic ROI (S-ROI) & Quantitative Impact Target Metrics
  - Climate Resilience & ESG Governance
  - Local Vernacular Summary for Gram Sabhas & Citizens

### 🤖 5. Strategic AI Policy Assistant Chat
- **Conversational Policy Intelligence**: Embedded AI copilot tailored for senior government officials, Cabinet Secretaries, District Magistrates, and NITI Aayog Fellows.
- **Context-Aware Analytics**: Queries active demand clusters, budget availability, and scheme guidelines (Jal Jeevan Mission, PMGSY, PM-ABHIM, PM Surya Ghar, Samagra Shiksha) to deliver actionable briefings.

### 🌐 6. Open DPG Standards & Interoperability
- **Standardized Data Schema**: Built to comply with India Digital Public Goods Registry standards, Beckn Protocol compatibility, Bhashini Multilingual Standard v2.0, and DPDPA privacy compliance (PII masking).
- **Public Open Data API**: Enables academic researchers, NGOs, and global development institutions to access anonymized demand indices via `/api/public-dpg/export`.

### 🔐 7. Dual-Role Stakeholder Portals
- **Citizen Portal**: Allows community leaders and citizens to submit multimodal reports, view nearby approved infrastructure projects, and track grievance statuses.
- **Official Government Portal**: Equips department heads and District Magistrates with approval workflows, budget signature tools, and audit trails.

## 🚦 Getting Started & Local Setup

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm** or **bun**: Package manager installed
- **Gemini API Key**: Required for server-side AI processing ([Get Key from Google AI Studio](https://aistudio.google.com/))

### Installation Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/CodeLander07/-CivicPulse-AI.git
   cd -CivicPulse-AI
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the root directory:
   ```env
   PORT=3000
   GEMINI_API_KEY=your_gemini_api_key_here
   VITE_GOOGLE_MAPS_API_KEY=your_google_maps_key_here
   ```

4. **Run the Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your web browser.

5. **Build for Production**:
   ```bash
   npm run build
   npm start
   ```

## 📡 API Reference Summary

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/ingest-citizen-request` | Ingests voice (audio base64) or text requests; returns translated intent, sector, urgency, and vernacular reply. |
| `POST` | `/api/generate-dpr` | Generates a complete PIB/EFC-compliant Detailed Project Report (DPR) JSON based on hotspot metrics. |
| `POST` | `/api/policy-assistant-query` | Returns structured policy advice from the AI Assistant based on active filters and demand clusters. |
| `GET` | `/api/public-dpg/export` | Open DPG export endpoint delivering anonymized demand schemas (CC-BY-4.0). |
| `GET` | `/api/health` | Health check endpoint returning system status and Gemini API configuration state. |
